Which data structure removes items in the order they were added?

  1. A Stack
  2. B Queue
  3. C Set
  4. D Max heap
Show answer Hide answer

B. Queue. A queue follows first in, first out (FIFO). The first item added is the first item removed.

NSCT study guide

Start with the HEC syllabus, then use practice questions to see which topics need another pass.

What is the NSCT?

The National Skill Competency Test is a computer-based assessment run by Pakistan's Higher Education Commission (HEC). The 2026 test assessed students in the seventh and eighth semesters of computing programmes.

What topics are on the NSCT syllabus?

HEC's published competency areas include programming, data structures and algorithms, operating systems, databases, networks and cloud computing, and analytical skills. Use the official syllabus for the full list and topic weightings.

How can I practise for the NSCT?

Pick a syllabus topic, answer a short set of MCQs without notes, then review each mistake. On PrepHub, you can import your questions from a CSV, set a time limit, and review your answers after the quiz.

Where can I find official NSCT results?

Use HEC's NSCT results page for official results. NSCT PrepHub is an independent practice tool.
